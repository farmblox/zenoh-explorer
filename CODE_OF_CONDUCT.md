# Code of Conduct

## The short version

Be decent. Assume the person you're replying to is trying to help.

## The longer version

We want this to be a project people are glad to contribute to. That means:

- Critique code, not people. "This will deadlock if two taps start at once" is
  useful. "Did you even test this?" is not.
- Assume good faith. Most disagreements are misunderstandings about context.
- No harassment, personal attacks, or discriminatory language. Not in issues,
  not in PRs, not in commit messages.
- If someone asks you to stop, stop.

## Unacceptable behaviour

Harassment, sustained disruption, publishing private information, sexualised
language or imagery, and personal or political attacks. Maintainers will remove
comments and, if needed, block accounts.

## Reporting

Email `conduct@farmblox.ag`. Reports stay private. If a maintainer is the
problem, say so — it will be handled by someone else.

## Scope

This applies in the repository, in issues and PRs, and anywhere someone is
representing the project.
